Resumo
Copia conteúdo de mark sets (documentos contendo marcas pré-definidas) para páginas alvo via funções estáticas. Não há evidência comportamental devido ao bloqueio de UI.

Entrada
- Documento de marca set (contendo 1+ páginas com marcas pré-definidas)
- Página alvo no documento de destino
- (Opcional) Estratégia de reutilização de marca
Pré-condições
- Documento de marca set existente e acessível
- Página alvo válida no documento de destino
- Modo de edição ativo

UI
- Menu: Marks > Create > Mark Sets
- Diálogo: "Criar Mark Set" com campo "Nome" (string, default "New Set", unidade: texto)
- Campo "Selecionar documento de marca set" (string, default vazio, unidade: caminho de arquivo)
- Botão "Aplicar" (ativado somente após seleção válida)
- Atalho: Ctrl+Shift+M

Regras
1. Carregar documento de marca set (função `?ReadMarkSetFile` em `0x18024e460`)
   - Verifica existência do arquivo
   - Carrega conteúdo em memória
   - Valida estrutura de marca set (versão ≥ 2.0)
2. Selecionar página alvo (função `?ApplyMarkSetToPage` em `0x18024d70`)
   - Identifica página alvo pelo índice ou nome
   - Prepara cache de marca (`PrepareMarksCachePage` em `0x180251790`)
3. Aplicar marca set (função `?ApplyMarksFromSet` em `0x18024d3e0`)
   - Percorre documentos de marca set
   - Para cada documento: copia primeira página para página alvo (`CopyMarksToPageWithLog` em `0x18024e9b0`)
   - Registra operação no log de marca
   - Atualiza cache de marca (`PrepareMarksCache` em `0x1454`)
4. Aplicar marca relevante (função `?ApplyRelevantMarkSets` em `0x18024d460`)
   - Identifica marca set relevante com base em critérios (nome, tipo, etc.)
   - Executa `MakeFormsFromMarks` para gerar formas de marca
   - Aplica formas às marcas existentes ou novas

Exceções
- Documento de marca set inexistente → erro "MarkSetFileDoesNotExist"
- Arquivo de marca set corrompido → erro "MarkSetFileError"
- Página alvo inexistente → erro "WrongMarkSet"
- Versão de marca set incompatível → erro "kVersionTooOld"/"kVersionTooNew"
- Falha na leitura do documento → erro "CannotOpenMarkSetFile"

Saída
- Conteúdo da primeira página de cada documento de marca set copiado para a página alvo
- Marcas atualizadas/refinadas com base nas formas geradas
- Log de operações de marca atualizado
- Nenhum efeito colateral no documento de marca set original

Em aberto
- Como o diálogo de licenciamento afeta especificamente as chamadas de API (ex: `ReadMarkSetFile` retorna erro específico?)
- Quais são os critérios exatos para "marca set relevante" em `ApplyRelevantMarkSets`?
- Existe suporte a múltiplos mark sets simultâneos? (ex: `ApplyRelevantMarkSetsWithReuse`)

> Inferência: O fluxo estático sugere que Mark Sets são documentos que contêm marcas pré-definidas, e o sistema copia o conteúdo da primeira página de cada documento de marca set para a página alvo no documento de destino. A ausência de CAP indica que o bloqueio de UI impede a validação direta do comportamento, mas as funções estáticas são bem mapeadas.
