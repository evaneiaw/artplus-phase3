# Resumo
Esta funcionalidade permite abrir documentos existentes no formato proprietário ou compatível com padrões abertos.
O sistema carrega o modelo de documento e suas camadas na memória.
Permite a edição e manipulação de objetos conforme o padrão definido.

# Entrada
Tipo de documento: Proprietário/Padrão Aberto. Seleção: Arquivo local ou caminho de rede. Camadas: Todas disponíveis no momento da abertura. Pré-condições: Arquivo válido e acesso de leitura concedido.

# UI
Caminho de menu: Documents > Open Document. Diálogo: Standard Open File Dialog. Campos: nome (string | auto-preenchimento | <nome_arquivo>), tipo (string | proprietário/padrão).

# Regras
1. O sistema detecta o tipo de arquivo (Proprietário ou Padrão Aberto) via heurística/extensão.
2. Carrega o conteúdo binário/estruturado para o modelo Document.
3. Para Padrão Aberto (ex: PDF), utiliza o parser PDF.
4. Se o carregamento for bem-sucedido, o documento é disponibilizado para edição.

# Exceções
Arquivo não encontrado: Exibe erro de I/O. Entrada inválida/corrompida: Reporta erro de parsing com detalhes do offset de falha. Documento sem camada: Permite abertura, mas alerta que não há camadas visíveis.

# Saída
Efeito: Documento carregado no viewport principal. Gravado no PDF: Estrutura do documento/camadas. Visual: Painel de documentos atualizado.
