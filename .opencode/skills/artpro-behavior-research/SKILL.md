# SKILL.md

Este documento serve como procedimento padrão para a skill de pesquisa de comportamento.

## Objetivo
Documentar o comportamento observável do software de referência de forma reproduzível.

## Critérios de Qualidade
- Documentado vs. Observado vs. Inferido.
- Evidências (screenshots, arquivos de teste).
- Nível de confiança.
